## Phase Goal

Build the anonymous offline-first editor and PWA foundation described in
`docs/SPEC.md` sections 3.2, 3.3, 5, and 8. This phase delivers the local document workspace:
React Router app shell, Dexie-backed storage, file tree, Tiptap editor, autosave, i18n, themes,
storage visibility, PWA offline behavior, and mobile navigation. Backend cloud sync, auth APIs,
uploads, migration, and public publishing remain out of scope.

## Contracts

> This section is the source of truth for `/context-update`. Fill it in **before** handing to AI.

### New persistent data (tables / collections / files)

No new PostgreSQL tables.

IndexedDB through Dexie:

```typescript
const db = new Dexie("notesapp_v1");
db.version(1).stores({
  nodes: "id, parentId, type, orderIndex, updatedAt, isDeleted",
  pages: "id, updatedAt",
  uploads: "id, pageId",
  pending_changes: "id, createdAt",
});
```

`uploads` stores base64 images for anonymous mode. During future migration, images upload through
`/api/upload/image`; returned URLs replace base64 references in Tiptap document JSON.

### New API endpoints / RPC methods / events

None.

### New types / models / shared interfaces

- `StorageAdapter`
- `LocalAdapter`
- `Page`
- `TreeNode`
- `CreateNodeInput`
- `LocalNode`
- `LocalPage`
- `LocalUpload`
- `PendingChange`
- `TiptapDocumentJSON`
- `ThemeMode` (`light`, `dark`, `system`)
- `LanguageCode` (`ru`, `en`)

Storage adapter contract:

```typescript
interface StorageAdapter {
  mode: "local" | "cloud";

  getPage(id: string): Promise<Page>;
  savePage(page: Page): Promise<void>;
  deletePage(id: string): Promise<void>;

  getTree(): Promise<TreeNode[]>;
  createNode(input: CreateNodeInput): Promise<TreeNode>;
  moveNode(id: string, newParentId: string | null): Promise<void>;
  renameNode(id: string, title: string): Promise<void>;
  deleteNode(id: string): Promise<void>;
}
```

New frontend state boundaries:

- Storage adapter state for local/cloud mode, currently initialized to `local`.
- Document tree state for expanded folders, selected node, ordering, and optimistic local actions.
- Editor state for active page, dirty/saving/error status, and debounced autosave.
- UI state for mobile drawer, language, theme, storage panel, and PWA install prompt.

### New env vars

None.
